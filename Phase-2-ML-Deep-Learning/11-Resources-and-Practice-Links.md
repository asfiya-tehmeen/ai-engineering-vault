## Learning path in one paragraph
Math intuition (3Blue1Brown) → Andrew Ng's ML Specialization or Kaggle Learn (classical ML) → Karpathy *Neural Networks: Zero to Hero* (build backprop + GPT) → PyTorch tutorials → fast.ai / d2l.ai / MIT 6.S191 for breadth → Stanford CS229/CS231n/CS224n for depth.

## Reading papers (start now)
Seminal: Backprop (Rumelhart 1986) · LeNet · AlexNet (2012) · Dropout · Adam · BatchNorm · ResNet · LSTM · word2vec · Attention (Bahdanau) · **Attention Is All You Need (2017)** · BERT · VAE · GAN · DDPM · CLIP. Method: read abstract+figures → intro → method → skim experiments → reimplement a core piece. Tools: arXiv https://arxiv.org/ , arXiv Sanity-style trackers, Hugging Face Papers, Yannic Kilcher / Umar Jamil videos. Habit: 1 paper/week, 1-paragraph summary in the vault.

## If you only have 3 weeks for the essentials
Week 1: Kaggle Learn ML + Géron ch. 1–7 · Week 2: Karpathy micrograd + makemore · Week 3: PyTorch basics + fine-tune a pretrained model + Deep-ML 20 problems.
